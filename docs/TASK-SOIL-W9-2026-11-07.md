## 1. The two features

| Woznicki | Our column | Source (SSURGO via NRCS Soil Data Access) | Coding |
|---|---|---|---|
| `fldfreq` | `soil_floodfreq` | `muaggatt.flodfreqdcd` of the map unit that contains the point (flooding frequency class, dominant condition; the same field Woznicki names, p. 944) | ordinal: None 0, Very rare 1, Rare 2, Occasional 3, Frequent 4, Very frequent 5; null → NaN |
| `fluvclass` | `soil_fluvclass` | the map unit's dominant component: highest `comppct_r`; ties broken by `majcompflag = 'Yes'`, then the lowest `cokey` | 1 if its `taxsubgrp` contains "fluv" (case-insensitive), 0 if not, 2 if the map unit is water. These are Woznicki's three classes: non-fluvial, fluvial, water (p. 945) |

Terms, in CS terms:
- **SSURGO** is the USDA county soil survey: a polygon map where each polygon is one *map unit*
  (key `mukey`), a mapped soil type. A map unit is a mix of *components* (soil kinds), each with a
  percentage of the unit (`comppct_r`). The *dominant component* is the largest.
- **Flooding frequency class** is the survey's estimate of how often the unit floods. In SSURGO,
  "None" is a class (no flooding), not a missing value (see the comment above `ATTRS` in
  `pull_ssurgo.py`).
- **Fluvial soils** formed from river deposits (subgroups such as "Typic Fluvaquents"). Woznicki
  uses them as a sign of past flooding.
- **Water map unit:** use the same definition as the `water_unit` column of `pull_ssurgo.py`
  (a regex `WATER_MU` on the map-unit name; reuse it, do not copy it).

Further rules:
- Woznicki filled SSURGO gaps with the coarser STATSGO2. Do not, unless Part A's stop on unmapped
  points fires; then ask Victor.
- Both columns enter every family as numbers, as `landcover` does now. Missing values follow the
  zoo's existing handling (median imputation except hgb and xgb). Do not add one-hot encoding.

**Claude's look at the existing cache** (the 323,147 polygons in
`data/interim/gis/ssurgo/*_mupolygons.parquet`, from the old region boxes, so not
representative of the state): `flodfreqdcd` None 89.2%, Frequent 2.9%, Occasional 2.0%,
Very frequent 1.6%, Rare 0.7%, null 3.7%; 10,579 of the 11,942 nulls are water units; no
"Very rare". Expect most land points in class 0. That is a fact about the data, not a problem.
